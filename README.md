\# AppsDev API Tutorial



A TypeScript and Express.js API project created for the AppsDev class activity.



\## Technologies Used



\* TypeScript

\* Node.js

\* Express.js

\* Prisma ORM

\* ESLint



\## Installation



Install the project dependencies:



```bash

npm install

```



\## Run the Project



For development:



```bash

npm run dev

```



The server will run at:



http://localhost:7000



\## Health Check



The project includes a health check route:



```text

GET /api/health

```
